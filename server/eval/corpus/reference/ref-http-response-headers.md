# Less Common HTTP Response Headers

## Security headers

- `X-Frame-Options`: Controls whether a page may be shown inside a frame, using DENY or SAMEORIGIN.
- `Referrer-Policy`: Controls how much referrer information the browser includes with outgoing requests.
- `Permissions-Policy`: Enables or disables browser features such as the camera or geolocation for a page and its frames.
- `Cross-Origin-Opener-Policy`: Isolates a page's browsing context group from windows opened by other origins.
- `Cross-Origin-Embedder-Policy`: Requires every cross-origin resource a page loads to explicitly allow being embedded.
- `Cross-Origin-Resource-Policy`: Lets a resource declare which origins may load it as a no-cors subresource.
- `Clear-Site-Data`: Instructs the browser to remove cookies, storage or caches for the site, for example on logout.
- `Content-Security-Policy-Report-Only`: Monitors policy violations and reports them without enforcing the policy.
- `Report-To`: Defines named endpoints where the browser should send violation and error reports.
- `Public-Key-Pins`: A retired header that pinned certificate keys to a host and is no longer supported.

## Content description

- `Content-Disposition`: Says whether content should display inline or be saved as an attachment, with a suggested file name.
- `Content-Encoding`: Names the compression applied to the body, such as gzip or br.
- `Content-Language`: Describes the human language of the intended audience for the content.
- `Content-Location`: Gives an alternate location for the content that was returned.
- `Content-Range`: Shows which part of a full resource a partial response carries.
- `Accept-Ranges`: Tells the client whether the server supports range requests, with a value of bytes or none.
- `Link`: Provides typed links to related resources such as preloads or the next page of results.
- `Server-Timing`: Passes backend performance metrics to the browser's developer tools.
- `Timing-Allow-Origin`: Lists origins permitted to see detailed resource timing data.
- `Last-Event-ID`: Used by event stream clients to tell the server the last event they received.

## Authentication and misc

- `WWW-Authenticate`: Sent with a 401 response to say which authentication scheme the client should use.
- `Proxy-Authenticate`: Sent with a 407 response to say which scheme a proxy requires.
- `Allow`: Lists the methods a resource supports, required on a 405 response.
- `Age`: Shows how many seconds a cached response has been stored in a proxy cache.
- `Expires`: Gives an absolute date after which a response is considered stale, used by older caches.
- `Pragma`: A legacy HTTP 1.0 header, where no-cache was used to ask caches to revalidate.
- `Date`: Gives the date and time at which the message was generated by the server.
- `Alt-Svc`: Advertises alternative network locations or protocols where the same service is available.
- `Trailer`: Announces which header fields will be sent after the body in a chunked message.
