# Common MIME Types

A MIME type names the format of a body in a Content-Type or Accept header, written as type and subtype.

## Application types

- `application/x-www-form-urlencoded`: The default encoding for HTML form submissions, with keys and values joined by ampersands.
- `application/octet-stream`: Arbitrary binary data, treated by browsers as a download.
- `application/pdf`: Portable Document Format files.
- `application/zip`: Zip archives.
- `application/gzip`: Data compressed with gzip.
- `application/xml`: Extensible Markup Language documents.
- `application/ld+json`: JSON-LD documents used for linked data and structured metadata.
- `application/problem+json`: A standard JSON format for describing errors returned by an HTTP API.
- `application/wasm`: Compiled WebAssembly modules.
- `application/vnd.api+json`: The media type of the JSON:API specification.
- `application/x-ndjson`: Newline-delimited JSON, with one JSON value per line.

## Text types

- `text/html`: HTML documents.
- `text/plain`: Plain text with no formatting.
- `text/css`: Cascading style sheets.
- `text/csv`: Comma-separated values tables.
- `text/javascript`: JavaScript source code.
- `text/markdown`: Markdown formatted text.
- `text/event-stream`: A stream of server-sent events kept open by the server.
- `text/calendar`: iCalendar events and calendar data.

## Image, audio, video and font types

- `image/svg+xml`: Scalable vector graphics images.
- `image/webp`: WebP images, supporting lossy and lossless compression.
- `image/avif`: AVIF images, based on the AV1 video codec.
- `image/png`: Portable Network Graphics images.
- `image/x-icon`: Icon files used for favicons.
- `video/mp4`: MP4 video files.
- `video/webm`: WebM video files.
- `audio/mpeg`: MP3 and other MPEG audio.
- `audio/ogg`: Ogg container audio.
- `font/woff2`: Web Open Font Format version 2 files.
- `font/ttf`: TrueType font files.
